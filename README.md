# Preposition corrections in heritage and foreign-language Russian

## Research question

Do heritage learners (HL) and foreign-language learners (FL) differ in the types of preposition corrections found in a sample of Russian government errors?

## Data

The project uses the manually annotated `rlc-goat` sheet from `rlc annotated`, based on RULEC within RLC-GEC. The analysed snapshot contains 485 observations: 175 HL and 310 FL. The separate HL and FL sheets are subsets and are not added to the main data.

## Files

- `prepositions_analysis.ipynb`: analysis, tables, plots and conclusions.
- `rlc-goat.csv`: input data, to be added separately.
- `README.md`: project description and instructions.
- `Project Proposal.md`: the original project proposal uploaded for HW2.

## Results

In the original snapshot, prepositions change in 33/175 HL observations (18.9%) and 56/310 FL observations (18.1%). The overall five-category difference mainly reflects the absent-in-both and retained categories. Among the 89 actual edits, there is no clear evidence that the groups differ in the distribution of insertions, deletions and substitutions. Exact test results appear in the notebook; rerun it if the CSV changes.

## Limitations

The dataset contains selected errors, without a denominator of all correct and incorrect preposition uses. Results therefore describe the composition of this sample, not overall accuracy. A nonsignificant result does not establish equivalence. The sentence check does not account for repeated writers; proficiency tables are descriptive. Sparse substitutions limit statistical power. Original annotation decisions are retained without new manual reclassification.
